The Robot Vacuum's Best Excuse: one original line in which a robot vacuum explains why it missed a spot — its cliff sensor panicked at a rug fringe and filed the whole corner as the edge of the world.

> My cliff sensor saw the rug fringe, panicked, and filed that corner as the edge of the world — I never argue with my own map.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` if set) and prints it to stdout. It refuses to run if the line is not 1–140 characters, so the gate can never see an invalid entry.
